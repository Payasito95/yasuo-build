# Yasuo Build

Build, runas y plan de juego de Yasuo en Wild Rift. Escanea la pantalla de carga con Gemini para detectar el rival.

La clave de Gemini se carga dentro de la app y queda solo en el celular. No va en este repositorio.

## App de Android (burbuja flotante)

Descarga: https://github.com/Payasito95/yasuo-build/releases/latest/download/yasuo-build.apk

La carpeta `android/` se compila sola con GitHub Actions en cada cambio. La burbuja solo saca una captura cuando se la toca; no lee ni modifica nada del juego.
